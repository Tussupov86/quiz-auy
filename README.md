# АЮ READY КВИЗ

Подсчёт баллов квиза с живой синхронизацией: один человек вводит счёт, у всех, кто открыл ссылку, баллы и места обновляются сами.

## Как пользоваться

- **Просмотр** — открыт всем по ссылке, ничего вводить не нужно.
- **Ввод счёта** — нажать «Ввод счёта». Телефон запоминает режим, при следующем открытии он включится сам.
- **Выгрузить** — «Скачать PowerPoint» (готовый слайд с итогами, все команды на одном слайде, строки появляются по щелчку от последнего места к первому) или «Копировать таблицу» для Excel.
- **Сбросить всё** — очищает счёт у всех (есть подтверждение).

## Размещение на Render (бесплатно, без домена)

1. На GitHub создайте новый репозиторий, например `ayu-quiz`.
2. Нажмите **Add file → Upload files** и перетащите содержимое этой папки: `server.js`, `pptx.js`, `pptx-template.json`, `package.json`, `README.md` и папку `public`. Нажмите **Commit changes**.
3. На render.com: **New → Web Service** → выберите репозиторий `ayu-quiz`.
4. Настройки:
   - Language / Runtime: **Node**
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Instance Type: **Free**
5. Нажмите **Create Web Service**. Через пару минут появится адрес вида `https://ayu-quiz.onrender.com`. Эту ссылку и отправьте помощнице.

Вводить счёт может любой, у кого есть ссылка, поэтому не публикуйте её в общих чатах.

## Особенности бесплатного тарифа

- Через 15 минут без посетителей сервис засыпает. Первое открытие после этого занимает до минуты. Откройте ссылку заранее, минут за 5 до начала.
- При засыпании счёт на сервере может стереться. Телефон того, кто вводит счёт, хранит копию и сам отправит её на сервер, как только откроет страницу снова.
